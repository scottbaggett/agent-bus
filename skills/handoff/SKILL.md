# handoff → agent-bus

This skill was renamed. Follow the **agent-bus** skill (`/agent-bus`) instead:
its "hand off" section covers handing work to another agent, and its other
sections cover checking the bus, reviews, decisions and setup.

If the agent-bus skill is not installed, run `agent-bus guide` for the playbook
and `agent-bus status` for where you stand.
